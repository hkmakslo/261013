Workshop/Ten prompts/07

Audit a teaching or assessment draft before use

Situation

A teacher wants Notebook to check a draft rather than make a flawed explanation sound more convincing.

Sources to add to Notebook

the original approved osmosis and diffusion notes; applicable curriculum guidance. Keep the draft below separate from those evidence sources.

The following sentence is an intentionally flawed workshop draft, not a fact to learn or a reference source.

Use one language version at a time. These are worked examples: adapt the source names to match your notebook.

English promptMarkdown / plain-text prompt

Check this intentionally flawed S4 HKDSE Biology draft against the original osmosis and diffusion notes:
‘Osmosis means that any dissolved substance moves through any membrane until its concentration is equal everywhere.’

Use a four-column table: Draft wording; Issue type; Source evidence; Correction. Classify issues as ‘contradicts source’, ‘unsupported’ or ‘teacher judgement’, with citations. Treat the draft as the checking target, not evidence.

Add one diagnostic question with a separate answer, two manual checks, and a brief use / revise / reject recommendation.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請對照原始滲透作用及擴散作用筆記，檢查以下刻意寫錯的HKDSE中四生物科草稿：
‘Osmosis means that any dissolved substance moves through any membrane until its concentration is equal everywhere.’

用四欄表格：草稿措辭；問題類型；來源證據；修正。分類為「與資料矛盾」、「未有支持」或「教師判斷」，並引用證據。草稿是檢視對象，不是證據。

另加一道診斷題及獨立答案、兩項人工核對事項，以及簡短使用／修改／不宜使用建議。

請以繁體中文回答。
Adapt this task: show the reusable templates

English promptMarkdown / plain-text prompt

Check [draft] for [level] HKDSE [subject/topic] against the selected original references, not the draft itself.

Use a four-column table: Draft wording; Issue type; Source evidence; Correction. Prioritise factual errors, unsupported claims and question–answer mismatches. Classify issues as ‘contradicts source’, ‘unsupported’ or ‘teacher judgement’, and cite the evidence. Flag leaked instructions/placeholders and sensitive content.

End with two manual checks and a brief use / revise / reject recommendation. This is a review, not an accuracy guarantee.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請對照所選原始資料，檢查HKDSE[科目／課題][年級]的[草稿]，不要用草稿證明自己。

用四欄表格：草稿措辭；問題類型；來源證據；修正。優先檢查事實錯誤、無支持聲稱及題目答案不符。分類為「與資料矛盾」、「未有支持」或「教師判斷」，並引用證據。指出誤成正文的指示／佔位字及敏感內容。

最後列兩項人工核對事項及簡短使用／修改／不宜使用建議；這不是準確性保證。

請以繁體中文回答。

Notebook grounds answers in selected sources, but grounding is not an accuracy guarantee. These prompts are workshop adaptations, not official EDB/HKEAA instructions. Check important claims against their cited passages.
